# 交管业务模拟应用（HarmonyOS / ArkTS）

> ⚠️ **非官方教学演示项目**：本仓库为课程设计作品，模拟「交管 12123」类应用的常见业务流程，**与任何政府机构、官方应用无关**；全部数据为本地模拟数据。界面素材仅用于学习交流，如涉及版权问题请联系删除。

基于 HarmonyOS **ArkTS / ArkUI** 的交通管理业务模拟 App，覆盖违章查询与处理、车驾管业务、资讯浏览、个人中心等模块，并做了多设备响应式适配。

## 技术栈

ArkTS / ArkUI / DevEco Studio / HarmonyOS API 9

## 功能模块

| 模块 | 内容 |
|---|---|
| 首页 | 业务快捷入口（违章查询、罚款缴纳、驾驶证业务、机动车业务、考试预约、年检预约…）、证件信息展示、搜索、消息 |
| 违章查询与处理 | 违章记录列表与详情、在线缴费流程 |
| 驾驶证与机动车业务 | 期满换证、年审、补证、注册登记、年检预约、临牌申领、号牌补办等办理入口 |
| 资讯与通知 | 最新公示、通知公告、新闻资讯，支持按类别筛选 |
| 个人中心 | 资料编辑、账号与安全、邮寄地址管理、意见反馈、设置 |
| 搜索与导航 | 全局搜索 + 底部导航栏切换 |

## 运行

1. 用 **DevEco Studio**（API 9 SDK）打开工程根目录 `harmonyos-traffic-app-demo`
2. 首次打开会自动安装 ohpm 依赖（`oh_modules/` 已在 `.gitignore` 中，不入库）
3. 选择模拟器或真机运行

> 若提示缺少 SDK 或签名配置，请在 DevEco Studio 中按向导配置本地 SDK 与调试签名后重新同步。

## 测试情况（课程设计）

在 DevEco Studio + HarmonyOS API 9 模拟器上完成功能、界面、兼容性、性能、安全性五类测试：

- 首页加载 **2.1s**（目标 ≤3s）
- 滑动帧率 **60FPS**（复杂页面目标 ≥45FPS）
- 多设备布局适配良好（手机 / 平板 / 折叠屏）
