# 酒店客房管理系统（Qt + MySQL）

独立开发的酒店客房管理桌面应用（课程设计）：**用户认证、客房管理、客户管理、预订管理、综合查询**五大模块，含数据库自动初始化与完整演示数据。

## 技术栈

Qt 6.5.3 / C++17 / MySQL 8.0（QMYSQL 驱动）/ Qt Widgets + Qt Designer / qmake / MVC 三层架构 + 单例模式

## 功能

| 模块 | 内容 |
|---|---|
| 用户认证 | 登录 / 注册；连续 3 次失败自动锁定、登录成功自动重置；管理员与普通员工角色区分 |
| 客房管理 | 增删改查、房间号唯一性校验、价格校验、删除前关联预订检查 |
| 客户管理 | 增删改查、身份证号 18 位与手机号 11 位正则校验、身份证号唯一性检查 |
| 预订管理 | 创建 / 修改 / 删除 / 查看；**预订冲突检测**（时间区间重叠）、预订与客房状态自动联动 |
| 综合查询 | 客房 / 客户 / 预订三类查询切换、多条件组合模糊搜索、日期范围筛选 |
| 系统辅助 | 启动欢迎页、双通道日志（控制台 + 文件）、数据库与表结构自动初始化 |

## 快速开始

1. 安装 **Qt 6.5.3（MinGW 64-bit）** 与 **MySQL 8.0**
   > 若运行时报 `QMYSQL driver not loaded`，说明当前 Qt 未安装 MySQL 驱动插件，需自行编译安装该驱动或改用自带驱动的发行版。
2. 修改数据库连接参数：`src/dbmanager.cpp` 第 19–23 行（host / port / dbName / user / pass）
3. 准备数据库（二选一）：
   - **自动初始化**：程序启动时自动建库、建表并写入默认管理员账号
   - **导入脚本**：`mysql -u root -p < sql/hotel_db.sql`（含完整表结构与演示数据）
4. 用 Qt Creator 打开 `src/hotel_management.pro`，构建并运行

**演示账号**（仅本地测试用）：管理员 `admin / 123456`，普通员工 `staff1 / staff123`

## 设计要点

- **MVC 三层架构**：表现层 / 业务逻辑层 / 数据访问层分工清晰；6 个 Manager 单例类（DbManager、UserManager、RoomManager、GuestManager、ReservationManager、QueryManager）保证全局唯一实例
- **预订冲突检测**：在 SQL 层做时间区间重叠判定 —— `新入住 < 已有退房 AND 新退房 > 已有入住`，仅检索有效状态记录，避免在代码中遍历全表
- **状态联动**：预订状态变更时自动同步对应客房状态（已预订 / 已入住 / 空闲），保证数据一致性
- **安全**：全部使用 `prepare()` + `bindValue()` 参数化查询防止 SQL 注入；前端正则实时校验
- **索引优化**：客房状态索引、`room_id + 日期` 联合索引，加速冲突检测与状态筛选
